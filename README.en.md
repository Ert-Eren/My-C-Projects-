## 📌 Overview
This repository is a comprehensive archive of my journey through C programming, spanning from fundamental `"Hello World"` routines to advanced data structures and systems concepts.

It organizes academic coursework (Programming Languages 1 & 2), laboratory implementations, graded problem sets, exam preparation solutions, and independent algorithmic experiments into a clean, modular structure.
